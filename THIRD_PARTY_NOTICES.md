## Hisaab map-rendering and interface reference

Repository: https://github.com/theadiram/Hisaab

The Bangladesh atlas uses an adapted screen-space country-silhouette clipping approach and interface direction informed by Hisaab's public map implementation and design. The Bangladesh implementation is independently adapted for this site's Leaflet map, administrative-boundary API, and Cloudflare Pages deployment; Hisaab's India geography and Mapbox-specific configuration are not included.
